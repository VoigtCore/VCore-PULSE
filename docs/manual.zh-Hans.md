**让机器拥有运行记忆。** Pulse 观察资源使用情况，将变化、影响与恢复过程联系起来，保留理解机器运行所需的上下文。操作系统可以改变，运行记忆的理念始终如一。

> 2026 年 9 月 28 日版。本文介绍 Pulse 2.2，**2.2 下载尚未开放**。本手册为后续使用提供指引，不代表平台已通过验收或已正式商用。请查看[平台状态](platforms-2.2.md)。本仓库仅提供公开文档，不包含私有引擎源代码。

## 1. 安装前的准备

版本开放后，请仅从[官方网站](https://www.voigtcore.com.br/?lang=zh-Hans#pulse22-manual)或[官方发布页面](https://github.com/VoigtCore/VCore-PULSE/releases)下载。核对版本、操作系统、处理器架构和发布状态。旧版下载即使与本手册同时出现，也仍然是其标注的版本。

Windows x64 与 Windows ARM64 不同。Intel Mac 和 Apple Silicon Mac 需要不同的软件包。Linux ARM64 是下一阶段的优先目标，并非已通过验收的平台。

## 2. 在 Windows 上安装或更新

1. 待相应版本开放后，关闭 Pulse，运行适合该系统的安装程序。
2. 使用原安装所用的 Windows 用户账户；本地密钥保护与该用户相关。
3. 等待安装完成，通过快捷方式打开 **VCore Pulse 2.2**。
4. 浏览器会打开本地面板 `http://127.0.0.1:4173`。此地址指当前电脑，而不是局域网中的另一台机器。
5. 检查版本、采集状态和历史记录。刚开始观察的机器需要时间积累运行轨迹。

更新时不要删除数据，也不要复制其他电脑的数据库来替换当前数据库。安装失败时，请保留错误代码及提示中的 `install.log`，然后联系支持。不要修改数据库结构来绕过检查。

v11 候选版本修复了已审核升级路径中旧安装缺少发布清单时的识别问题。`UPDATE_INSTALL_SCHEMA_UNKNOWN` 仍会阻止未知内部版本；此前出错的电脑仍需重新验证。

## 3. 认识主面板

![Pulse 实际面板，来自此前版本的参考截图](../screenshots/dashboard.png)

本手册使用此前公开的真实截图。2.2 的界面可能有所不同，这些图片不能作为新安装程序已通过验收的证据。

- **运行健康状态：** 根据观察到的数据提供总体概览及上下文。
- **变化响应与恢复：** 展示机器如何应对变化并恢复到日常行为。
- **不稳定性：** 观察期间检测到的波动。
- **历史记录：** 可用运行记忆的时间跨度与连续性。关机时间不等于持续观察。
- **进程与资源：** CPU、内存、磁盘及该平台可用传感器的数据。

高评分不保证不会发生故障。Pulse 帮助解读证据，不能替代备份、杀毒软件或负责团队的判断。

## 4. 阅读图表与运行轨迹

![Pulse 实际时间线](../screenshots/timeline.png)

选择可用时间范围，将变化、影响和恢复联系起来。按日期或时段查看记录，区分单次事件与重复模式。图表反映测量值的变化趋势；请同时关注上下文和样本数量。样本不足时，比较结果应显示为不可用，而不是推断机器运行正常。

历史记录与该机器的身份关联。切换语言不会创建新身份，也不会改变已有记录。

## 5. 报告、通知与语言

![Pulse 报告界面](../screenshots/reports.png)

选择可用周期以查看或生成报告。Pulse 2.2 改进了周期比较、执行摘要和运行事件说明，让图表与实际发生的情况建立联系。没有样本的时间段不能被当作正常运行的证据。

电子邮件和 Telegram 发送功能需要明确配置。确认收件人并检查发送结果；提交发送请求不等于消息已送达。

面板支持**葡萄牙语、英语、西班牙语、简体中文和繁体中文**。在面板中选择语言后，数据及机器身份保持不变。

## 6. 试用、许可证与付款

请以产品中显示的最新条款为准。当前文档中的方案包括 10 天试用，以及每台机器每月 R$ 79,90 的 Pulse Solo；付款前请核对金额、期限及可用性。

1. 打开购买许可证或续订许可证选项。
2. 填写购买者信息和税务地址，核对方案与期限。
3. 选择 **Pix**，请求生成二维码和可复制的付款代码。按提示确认电子邮件，然后返回 Pulse。
4. 在银行应用中核对收款人和金额后再付款。
5. 等待确认，或使用已付款检查选项。显示二维码本身不会激活许可证。

**银行卡：** 付款在 C6 的安全结账页面完成。本地 Pulse 面板不要求填写卡号、有效期或 CVV。

**已选择银行卡，现在想改用 Pix？** 使用结束未付款尝试并选择 Pix 的操作。应用会等待银行确认。已付款、处理中或结果不确定的尝试都不能自动触发新的收费。确认结束后，重新核对信息并请求生成 Pix。

如果许可证通过电子邮件送达，请按邮件指引操作。能够使用某台电脑不代表有权访问其他客户的商业账户。

## 7. 关闭、重启与保留运行记忆

维护前请使用 Pulse 的退出功能，再通过快捷方式重新启动观察。数据库写入期间不要删除数据库文件或强行终止进程。

产品可能将较早的时间段整理为历史文件。不要删除历史分段、控制记录或受保护的材料。导出报告并不等于完整备份。恢复数据或迁移到其他用户、电脑时，需要遵循支持流程，并确保相应密钥可用。

## 8. Linux 与 macOS

候选包已生成，但仍需针对各平台验收。本轮已验证的 SQLCipher 适配器是 Windows x64 版本；Linux 仍需原生适配器和密钥管理验证，macOS 需要在 Mac 上测试。不要通过关闭加密来宣称安装成功。在没有验证备份与回滚流程之前，不要用候选包替换正在运行的安装。

## 9. VLP 与后续发展

VLP 为生态系统集成提供身份与权限基础。安装 Pulse 不会自动连接 VCore Server。每项集成都取决于版本、配置及验证状态。

下一步优先考虑 Linux ARM64，其后是 Windows ARM64。FreeBSD 和企业 Unix 系统属于取决于需求的未来方向，并非当前支持的平台。
