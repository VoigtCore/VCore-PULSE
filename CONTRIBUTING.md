# Contribuindo

O repositório público recebe relatos e sugestões para a Public Beta. O código-fonte dos motores não faz parte desta distribuição.

## Reportar bugs

Abra uma [Issue](https://github.com/VoigtCore/VCore-PULSE/issues) incluindo:

1. versão do Pulse e sistema operacional;
2. comportamento observado e comportamento esperado;
3. passos para reprodução;
4. data e horário aproximados;
5. captura de tela ou diagnóstico sem informações sensíveis.

Antes de abrir, pesquise Issues existentes e confirme o hash do instalador.

## Sugerir melhorias

Abra uma Issue com o prefixo `Sugestão:` e explique o problema que a proposta resolve. Durante a estabilização, correções e calibração têm prioridade sobre novas funcionalidades.

## Pull requests

Pull requests podem ser utilizados para corrigir documentação pública. Mudanças de produto, binários ou hashes somente são publicadas pela equipe VoigtCore.

Ao participar, você concorda com o [Código de Conduta](CODE_OF_CONDUCT.md).
