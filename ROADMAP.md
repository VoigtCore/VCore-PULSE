# Roadmap — VCore Pulse

[Português](docs/manual.pt-BR.md) · [English](docs/manual.en.md)

1. Windows x64 v16: aceito pelo responsável; assinatura de distribuição pendente / Owner-accepted; distribution signing pending.
2. Linux x64 e macOS x64/ARM64: concluir aceitação manual, serviços e cofres nas VMs do usuário / Complete user-VM acceptance, services and OS vaults.
3. Linux ARM64: pacote gerado; ampliar validação de hardware, sensores e distribuições / Package built; extend hardware, sensor and distribution validation.
4. Windows ARM64: prioridade posterior / Later priority.
5. FreeBSD: estudo futuro / Future study.
6. AIX, Solaris, HP-UX, z/OS: somente com demanda / Only with commercial demand.

Não são datas ou suporte prometidos. / These are not promised dates or supported targets.

O sistema operacional muda. A Memória Operacional permanece. / The operating system changes. Operational Memory remains.
