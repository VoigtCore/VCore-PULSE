# Política de Segurança

## Versão suportada

| Versão | Suporte |
|---|---|
| 2.0 RC2 Public Beta | ✅ |
| Versões anteriores | ❌ |

## Reportar uma vulnerabilidade

Não publique vulnerabilidades exploráveis em uma Issue aberta. Envie um relato privado para [rafael@voigtcore.com.br](mailto:rafael@voigtcore.com.br) com:

- versão e sistema operacional;
- descrição do impacto;
- passos mínimos para reprodução;
- evidências sem dados pessoais ou credenciais;
- sugestão de correção, se houver.

O recebimento será confirmado assim que possível. A correção, divulgação e eventual reconhecimento serão coordenados de forma responsável.

## Dados sensíveis

Nunca envie tokens do Telegram, chaves de licença, certificados, credenciais bancárias, bancos `pulse.db` completos ou diagnósticos sem revisar o conteúdo.
